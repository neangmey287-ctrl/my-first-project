មូលហេតុដែលមើលទៅដូចជាត្រូវធ្វើច្រើនដងមិញនេះ គឺដោយសារតែលើកទី១ យើងវាយពាក្យបញ្ជាខ្វះ (វាយត្រឹម git commit -m តែគ្មានដាក់សារពណ៌នា) ធ្វើឱ្យប្រព័ន្ធវាចេញ Error ហើយការ Commit នោះ បរាជ័យ មិនបានកត់ត្រាទុកទេ។ ដូច្នេះហើយ បានជាពេលយើងវាយ git push វាមិនមានទិន្នន័យថ្មីសម្រាប់ផ្ញើឡើយ។

មូលហេតុដែលធ្វើឱ្យអ្នកកែប្រែ HTML ក្នុង VS Code ហើយ តែពេល git status ឬ git add វាមិនឃើញមានអ្វីផ្លាស់ប្តូរ គឺមានកត្តាតែមួយគត់៖ អ្នកមិនទាន់បាន Save ឯកសារនោះទេ (រឿងហ្នឹងកើតឡើងញឹកញាប់ណាស់សម្រាប់អ្នកសរសេរកូដថ្មីៗ)។
